STEP 1

어디에서 찾을까요?

위치를 등록하면 가까운 식당을 우선으로 볼 수 있어요. 위치 권한이 안 되면 학교 주변 기준으로 이용하세요.

아직 위치를 등록하지 않았어요. 학교 기준 버튼을 누르면 주변 식당 목록을 볼 수 있어요.

면? 밥? 다른 음식?

STEP 3

어떤 종류가 좋을까요?

먼저 위치와 음식 조건을 선택해 주세요.
조건을 선택한 뒤 식당을 찾아보세요.
※ 외부 API 없이 작동하는 단일 HTML 앱입니다. 식당명·주소·일부 영업시간은 온라인 장소 정보에서 확인한 주변 매장 기준이며, 브레이크타임과 휴무일 등 확인되지 않은 값은 ‘확인 필요’로 표시했습니다. 운영 정보는 바뀔 수 있으니 방문 전 지도/매장 공지로 확인해 주세요.

맛있게 드세요! 😋

선택한 식당은 이 브라우저에 저장되며 최근 3일 동안 추천에서 제외됩니다. 전체 기록은 7일이 지나도 삭제되지 않아요.

🕒 최근 선택 기록

최근 3일 선택은 추천에서 제외하고, 7일 이내 기록도 별도로 확인할 수 있어요.

사용 팁

① 위치 등록 → ② 면/밥/기타 선택 → ③ 음식 종류 선택 → ④ 식당을 골라 기록하세요.

조건을 여러 개 고르면 선택한 종류 중 하나라도 맞는 식당을 보여줘요. 면과 밥을 모두 파는 곳은 두 조건 모두에 포함됩니다.

메뉴 추천 · 데이터는 현재 사용 중인 브라우저의 localStorage에 저장됩니다. 다른 기기/브라우저와 기록이 공유되지 않습니다.
